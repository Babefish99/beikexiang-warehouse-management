# 首页视觉、通知中文化与新增物品弹窗设计

## 背景

当前首页指标卡和业务快捷入口使用基础线性图标，通知中心直接展示了英文通知内容，侧边栏底部信息板字号偏小，标准物品库的新增表单长期占据页面空间。

## 目标

让首页图标、通知、信息板和物品库页面更符合现有集团仓库后台的视觉主题，并减少标准物品库的页面纵向占用。

## 设计决策

### 首页图标

- 以图片工具生成的第一版粗线块面造型作为设计参考，不直接把整张位图放入页面。
- 使用代码内矢量图实现，保留清晰的实心块面、粗线条和明确的业务象征。
- 四个指标卡分别使用：仓储货架、审批清单、入库箱体、出库箱体。
- 图标尺寸控制在指标卡现有图标容器内，颜色沿用深蓝、蓝色、绿色和橙色，背景继续使用浅色圆角底块。
- 业务快捷入口使用同一视觉语言的紧凑图标，不改变现有链接地址和操作行为。

### 通知中心与英文清理

- 通知服务直接返回中文标题和描述，避免前端继续显示英文通知。
- 将侧边栏和移动导航中的 `Inventory Center` 改为中文“库存管理后台”。
- 不改变通知类型、优先级、跳转地址和未读状态逻辑。

### 信息板

- 左下角侧边栏信息板主标题使用 14px，辅助说明使用 12px。
- 增加信息板最小高度和内边距，保持深色侧边栏中的视觉平衡。

### 新增物品

- 标准物品库页面只保留页面右上角“新增物品”按钮，不再渲染常驻新增表单。
- 点击按钮打开与编辑物品一致的弹窗样式。
- 新增弹窗保留现有字段、校验、保存接口和错误保留输入行为。
- 保存成功后关闭弹窗、清空表单并刷新列表；取消、关闭按钮和 Escape 均关闭弹窗。
- 编辑物品弹窗行为保持不变。

## 验收标准

1. 首页四个指标卡和三个快捷入口图标与现有 UI 配色、尺寸和线条重量统一。
2. 管理员打开通知中心时，通知标题和描述均不出现英文句子。
3. 页面可见的品牌副标题不再显示 `Inventory Center`。
4. 左下角信息板主标题和辅助说明字号分别达到 14px 和 12px。
5. 标准物品库页面不显示常驻新增表单，只显示“新增物品”按钮。
6. 点击“新增物品”能打开弹窗，提交成功、失败保留输入、取消和关闭均符合预期。
7. 既有首页快捷入口、物品编辑、通知未读状态和 API 行为不受影响。
