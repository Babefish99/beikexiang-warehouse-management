# 集团仓库管理系统中等窗口紧凑桌面布局设计

## 1. 背景与目标

企业微信桌面端的小窗口会让仓库系统同时保留完整的 `232px` 侧栏、完整顶部控件和四列首页指标卡，主内容区因此显得拥挤。固定资产系统保持了相同的企业视觉语言，但其栅格在较窄桌面窗口中更稳定。

本次只调整仓库系统前端的桌面响应式呈现。目标是在企业微信小窗口、普通笔记本和大屏之间维持一致的层级、可读性和操作空间，而不是把整个页面等比缩小。

## 2. 已确认的产品决策

采用“响应式紧凑桌面模式”：

- 视口大于 `1180px` 时，保留当前完整侧栏和桌面布局；
- `821px–1180px` 时，默认显示 `64px` 的仅图标侧栏；
- 紧凑侧栏支持鼠标悬停、键盘聚焦和顶部切换按钮；悬停仅临时展开，点击按钮则保持完整菜单直至再次点击；
- 悬停展开以高层级浮层覆盖主内容边缘，不改变主内容区宽度或触发布局跳动；点击固定展开后，主内容区同步切换为完整侧栏留边；
- 视口不大于 `820px` 时，继续使用已验收的手机底部导航，不改变现有手机业务流程；
- 不采用整体等比缩放，以免文字、表单和触控目标变小。

## 3. 呈现与交互设计

### 3.1 侧栏

紧凑模式仍使用深蓝背景、橙色选中态和现有 Lucide 图标。默认状态只展示：

- 公司标识的紧凑呈现；
- 所有导航图标及当前页选中态；
- 具有可读标签的悬停提示；
- 可访问的“展开/收起菜单”按钮。

默认紧凑状态下，工作区按 `64px` 留边。鼠标进入侧栏或键盘焦点进入侧栏时，侧栏临时以浮层方式展开至完整宽度；离开后恢复紧凑状态。点击顶部展开按钮会切换“固定展开”状态：固定后工作区同步按 `232px` 留边，鼠标移出和焦点离开均不收起，直到用户再次点击该按钮。展开状态须：

- 悬停展开覆盖而非推动工作区，避免鼠标移动时首页反复重排；固定展开才以一次明确切换同步工作区留边；
- 显示完整 Logo、导航文字和底部运行状态；
- 由按钮以 `aria-expanded` 表达，按钮文案和辅助说明明确表示再次点击可收起；
- 在触控或无 hover 环境中完全可通过按钮使用，不依赖 hover；
- 固定展开状态不写入本地存储，刷新页面后在紧凑宽度恢复默认收起。

导航项仍直接跳转既有 URL；本次不增加路由、权限或业务逻辑。

### 3.2 顶部栏和页面间距

在中等窗口下，顶部栏保留仓库选择、统一搜索、通知和当前用户，但使用可收缩的区域：

- 次要面包屑文字可隐藏，当前页面名称保留；
- 仓库名称、搜索输入和用户名称使用截断，不能挤出顶部栏；
- 用户按钮在空间不足时优先保留头像、角色与菜单入口，省略冗长名称；
- 页面左右内边距使用流式值，介于手机端和大屏端现有间距之间。

控件不通过 CSS 缩放；它们保持现有可点击高度和可读字号。

### 3.3 首页与通用网格

为避免卡片随窗口变窄而出现文字重叠或不均衡空白：

- 首页指标在宽桌面为四列；紧凑桌面优先保持四列并缩减非必要内边距；当可用宽度不足以容纳卡片内容时切为两列两行；
- 首页快捷入口与运行状态在中等窗口切为单列，减少两个窄面板同时出现；
- 通用页面保持已有的表格滚动策略和表单断点；为本次布局新增的断点不得制造页面级横向滚动；
- 卡片、按钮、颜色、圆角和字体继续沿用现有仓库系统与固定资产系统的共同视觉语言。

## 4. 技术边界

- 只修改 `apps/web` 中的应用壳层、相关样式和对应前端测试；
- `AppShell` 负责紧凑侧栏的显式固定展开状态、临时悬停/焦点展开和可访问属性；该状态只保存在 React 内存中；
- 纯展示的宽度、栅格、溢出和流式间距优先由 CSS 媒体查询处理；
- 不修改 API、数据库、企业微信配置、固定资产项目或生产部署；
- 不改变 `820px` 及以下已有的移动挂载逻辑和底部导航。

## 5. 测试与验收

按测试驱动执行：先为紧凑侧栏状态写失败的前端测试，再实现最小壳层状态与 CSS。

自动化测试至少覆盖：

1. 在 `821px–1180px` 的紧凑模式，侧栏默认提供导航图标及可访问的展开按钮；
2. 点击按钮可固定展开或再次点击收起完整菜单，`aria-expanded` 正确；固定展开后移出鼠标或移走焦点仍保持展开；
3. 现有 `<=820px` 手机导航行为不回归；
4. 管理员与财务现有导航项和 URL 不变。

人工视觉验收至少使用 `820px`、`980px`、`1180px` 和大于 `1180px` 四档宽度，检查：

- 无页面级横向滚动、文字重叠或被裁切的主要操作；
- 悬停展开不改变主内容宽度；点击固定展开时，主内容以一次明确状态切换同步为 `232px` 留边；
- 顶部栏、指标卡、首页面板和常用表单在各档宽度保持可读；
- 键盘焦点可临时展开菜单，展开按钮可固定或收起菜单；刷新后紧凑状态恢复默认收起。

完成前还须运行针对性测试、完整测试、类型检查、生产构建和 `git diff --check`。完成后更新 `PROJECT_STATUS.md` 与 `docs/项目状态与发布交接.md`，明确记录本地改动和未部署状态。

## 6. 明确不在范围内

- 全页面等比缩放或浏览器缩放控制；
- 改造固定资产系统；
- 新增或变更业务接口、权限、数据库字段或企业微信登录；
- 修改生产 Secret、生产数据库、企业微信后台、Push 或部署。
