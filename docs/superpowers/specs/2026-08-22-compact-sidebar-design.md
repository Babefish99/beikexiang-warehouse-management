# 紧凑侧栏设计

## 目标

当企业微信桌面窗口宽度不足约 1180px 时，仓库管理系统采用固定资产系统风格的紧凑侧栏：默认仅显示图标，指针悬停时临时展开；点击切换按钮后保持展开，直到再次点击。

## 范围与断点

- 大屏（`min-width: 1181px`）：保留现有完整 232px 侧栏。
- 紧凑桌面（`821px–1180px`）：默认 64px 宽，仅显示导航图标；可临时或固定展开为 232px。
- 手机（`max-width: 820px`）：继续使用现有底部导航和更多面板，不渲染桌面侧栏。

## 交互

1. 紧凑桌面初始为收起状态。
2. 鼠标悬停收起的侧栏时，侧栏临时展开；鼠标移开后恢复收起，除非用户已经固定展开。
3. 侧栏顶部的切换按钮可固定展开或收起。固定展开会持续到用户再次点击该按钮。
4. 切换状态只在当前页面运行期间保存；刷新页面后，紧凑桌面恢复默认收起。
5. 导航链接、激活状态和手机导航的既有行为保持不变。

## 布局与可访问性

- 收起状态下，工作区按 64px 左侧留白；宽侧栏和已固定展开状态按 232px 左侧留白。
- 悬停展开覆盖工作区左缘，不改变工作区留白，避免内容横向跳动。
- 切换按钮使用清晰的展开/收起图标、中文无障碍标签和 `aria-expanded`。
- 收起状态下每个导航项保留文本可访问名称，并显示浏览器原生提示文本。

## 实现边界

- React 仅管理“固定展开”布尔状态并向侧栏添加状态类；响应式宽度、悬停效果和工作区留白由 CSS 媒体查询控制。
- 不引入本地存储、服务端状态、路由变更或手机端新逻辑。
- 不修改企业微信、认证、库存、生产配置或部署文件。

## 验收与测试

- 1180px 以下、821px 以上的桌面状态默认呈紧凑侧栏。
- 点击切换按钮可固定展开，再次点击恢复紧凑状态，并更新无障碍状态。
- 悬停只产生临时展开效果，不覆盖用户已固定展开的选择。
- 1181px 及以上保持完整侧栏，820px 及以下保持移动端导航。
- 为新增的侧栏状态和断点契约先写失败测试，再执行最小实现；完成后运行针对性测试、类型检查、完整测试与生产构建。
