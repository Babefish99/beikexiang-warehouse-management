# 集团仓库期初数据导入模板设计

## 目标

根据 `D:\桌面\酒水2026年7月.xlsx` 的“基础资料”和“汇总”工作表，生成一份不覆盖原文件的新工作簿 `集团仓库期初数据导入模板.xlsx`。模板用于收集三仓实盘数据、复核三仓合计与原综合库存的差异，并作为后续系统 Excel 导入功能的固定输入格式。

本次只创建模板文件，不导入本地或生产数据库，也不修改仓库系统代码。

## 仓库映射

沿用系统现有固定仓库编码，避免模板与数据库中的 `WH-01`、`WH-02`、`WH-03` 映射冲突：

| 仓库编码 | 正式名称 |
| --- | --- |
| `WH-01` | 集团二楼仓库 |
| `WH-02` | 内区1号仓库 |
| `WH-03` | 1区车库后仓库 |

## 工作簿结构

### 1. 填写说明

- 说明填写顺序、颜色含义、必填项和禁止修改的公式列。
- 提供一个可编辑的“盘点基准日期”输入单元格，不在模板中假定正式导入日期。
- 黄色单元格表示需要人工填写；灰色单元格表示公式或引用值；红色表示阻塞性错误；绿色表示校验通过。
- 明确“空白数量”表示尚未盘点，`0` 才表示已盘点且库存为零。
- 明确正式导入前必须消除所有阻塞性错误，并由管理员和财务共同确认。

### 2. 仓库清单

- 固定列：`仓库编码`、`仓库名称`、`状态`。
- 预填上述三个仓库，状态均为“启用”。
- 该工作表是期初库存仓库名称查找和数据验证的唯一来源。

### 3. 物品资料

- 从原“基础资料”预填 81 条物品。
- 固定列：`物料编号`、`物品名称`、`类别`、`单位`、`规格`、`参考单价`、`数据状态`、`问题说明`。
- `物料编号`按文本保存，导入时作为稳定业务键；同名物品允许使用不同编码区分。
- `参考单价`只作为期初库存“确认单价”的建议值，不作为系统物品主数据字段。
- 自动标记重复物料编号、必填字段为空、类别异常和参考单价缺失。
- 已知异常需保留并显式标记：`WP0010` 的类别为“个”，可能发生列错位；同名的 `WP0001`/`WP0010` 和 `CY0017`/`CY0018` 需要人工确认，但不同编码本身不构成阻塞。

### 4. 期初库存

- 按“每个物品连续三行、分别对应三个仓库”的方式预生成 `81 × 3 = 243` 条盘点行。
- 固定列：
  1. `仓库编码`
  2. `仓库名称`
  3. `物料编号`
  4. `物品名称`
  5. `类别`
  6. `单位`
  7. `规格`
  8. `批次号`
  9. `实盘数量`
  10. `确认单价`
  11. `金额`
  12. `备注`
  13. `校验状态`
  14. `错误说明`
- 仓库名称、物品名称、类别、单位和规格由固定清单查找，不要求用户重复录入。
- 批次号由“盘点基准日期 + 仓库编码 + 物料编号”生成稳定文本；基准日期未填写时标记错误。
- `实盘数量`必须逐行填写，允许 `0`，不允许负数；空白表示尚未完成盘点。
- `确认单价`优先带入“物品资料”的参考单价。数量大于零时单价必须存在且不得为负；数量为零时允许单价为空。
- `金额`使用公式 `实盘数量 × 确认单价`，不写死计算结果。
- 同一“仓库编码 + 物料编号 + 批次号”不得重复。

### 5. 核对汇总

- 按 81 个物料编号各占一行汇总三仓实盘数量和金额。
- 固定列：`物料编号`、`物品名称`、`原综合期末库存`、`三仓实盘合计`、`数量差异`、`三仓金额合计`、`核对状态`、`问题说明`。
- 对原“汇总”中的 78 条记录带入“期末库存”作为参考总量；`BJ0009`、`BJ0034`、`BJ0051` 标记为“原汇总缺失”。
- `CY0008` 的原综合期末库存为 `-1`，作为源数据异常显示，不复制成任何仓库的实盘数量。
- 三仓实盘合计通过公式汇总“期初库存”，并与原综合期末库存计算差异。
- 只有三个仓库的数量都已填写、行级校验均通过且数量差异为零时，物品核对状态才显示“通过”。

## 数据边界与导入约定

- 模板用于数据采集和校验，不自动连接或写入数据库。
- 系统读取“填写说明!B6”作为盘点基准日期，并读取“物品资料”和“期初库存”作为业务数据；仓库清单和核对汇总仅供人工辅助审核。服务端重新计算批次、金额和校验状态，不信任公式缓存。
- 正式导入采用“预览校验 → 用户确认 → 整批事务写入”；任一阻塞性错误会阻止整批写入，不允许部分成功。
- 导入时以仓库编码和物料编号解析系统内部 ID，不以中文名称作为业务键。
- 原《酒水2026年7月.xlsx》保持只读，不被覆盖或重命名。

## 验证标准

- 工作簿包含且仅包含上述五个工作表，名称和字段顺序固定。
- 物品资料为 81 行，期初库存为 243 行，仓库映射为 3 行，核对汇总为 81 行。
- 三仓实盘合计、金额和差异均由公式驱动；修改黄色输入格后结果自动更新。
- 负数、空白数量、正库存缺单价、重复键、未知仓库/物品及源数据异常都有清晰提示。
- 关键范围无 `#REF!`、`#DIV/0!`、`#VALUE!`、`#NAME?` 或意外 `#N/A`。
- 五个工作表均完成视觉渲染检查，标题、表头、说明、状态和重要数值在正常缩放下无裁切。
- 最终文件保存到项目的 `outputs/warehouse-initial-import-template/`，不提交原始业务数据或输出工作簿到 Git。
