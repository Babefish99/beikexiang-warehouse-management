# 仓库顶部导航对齐设计

## 目标

提升仓库系统顶部导航的可读性和关联感：放大“首页”，统一仓库选择按钮的字号，并让搜索框紧邻“全部仓库”按钮。固定资产系统继续使用已经接入并正常显示的贝壳祥集团横版 Logo，不重复修改。

## 已确认方案

- 顶部从左到右保持“集团仓库管理系统 / 首页 → 全部仓库 → 搜索框 → 通知和登录信息”的顺序。
- “首页”使用 16px 字号；“全部仓库”按钮使用 14px 字号。
- 搜索框功能、搜索结果浮层和仓库筛选逻辑保持不变，仅调整布局位置。
- 桌面端搜索框与仓库按钮的水平间距保持在 12–28px。
- 1080px 以下允许顶部换行，搜索框占据下一行；820px 和 640px 以下沿用现有移动端行为。
- 固定资产系统的 `public/beikexiang-logo.png` 与 `LogoMark` 已正常工作，本次不修改固定资产代码。

## 实现方式

仅修改仓库系统顶部壳层样式，不调整 React 组件结构。桌面端将 `.topbar` 从三列网格改为弹性布局；`.topbar__leading` 保持内容宽度，`.topbar__center` 紧随其后并提供最多 420px 搜索宽度，`.topbar__actions` 通过自动左边距固定在右侧。

## 验收

- Playwright 在桌面视口读取真实元素几何位置和计算字号。
- 旧布局因搜索框距离过大、字号不符而失败。
- 修改后搜索框紧邻仓库按钮，右侧通知和用户入口仍可见。
- 完整端到端测试、类型检查和生产构建通过。
