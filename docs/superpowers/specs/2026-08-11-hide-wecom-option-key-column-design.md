# 隐藏企业微信选项 key 列设计

## 背景

标准物品库当前在列表中展示“企业微信选项 key”。该字段主要用于企业微信审批单物品映射，当前不承担库存管理人员日常查看物品的职责。

## 目标

减少物品列表中的技术字段，让管理员更快查看编码、名称、规格、单位、状态和操作信息。

## 设计

- 从标准物品库列表移除“企业微信选项 key”表头和对应单元格。
- 保留 `weComOptionKey` 后端字段、接口返回和数据模型，保证企业微信审批映射能力不受影响。
- 保留新增物品和编辑物品弹窗中的 key 字段，便于管理员维护已有映射。
- 保留按 key 搜索能力，方便排查审批映射关系。
- 不调整库存、出入库、审批解析和数据库结构。

## 验收标准

1. 标准物品库列表不再出现“企业微信选项 key”列。
2. 物品列表仍展示编码、物品名称、规格、单位、状态和操作列，排版保持整齐。
3. 新增和编辑物品仍可读写企业微信选项 key。
4. 输入 key 仍能筛选对应物品。
5. 现有物品管理、审批映射和全量测试不受影响。
